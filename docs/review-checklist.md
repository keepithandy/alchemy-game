# Review Checklist

Use this before merging an Alchemy Game patch.

- Confirm core mixing/crafting interactions still respond correctly.
- Keep recipe discovery readable and avoid hidden state changes.
- Check menus, buttons, and result panels at narrow mobile widths.
- Avoid balance changes unless the patch explicitly targets progression.
- Verify failed combinations explain what happened without blocking the next action.
- Keep visual polish separate from recipe logic where possible.

Prefer small interface and feedback improvements over broad system rewrites.
